# Mapping to SETI Institute Pipeline Scientist

This independent portfolio project is a controlled synthetic benchmark, not mission software and not a performance claim for TOLIMAN or GOES GLM.

| Advertised responsibility | Inspectable evidence |
|---|---|
| Develop science algorithms and maintainable Python pipelines | Installable package, CLI, separate astrometry/rare-event modules, deterministic configuration |
| Validation plans, unit tests and formal V&V | Seven tests, explicit release gates, injection-recovery, group-leakage checks, machine-readable metrics |
| Revise analytical models after integration testing | Null/full astrometric models, nuisance regression, BIC decision rule, amplitude bias tracking |
| Space-based science data and instrument-quality effects | Astrometric nuisance channels (thermal, pointing, PSF) and contextual rare-event features |
| Machine learning for rare events | Imbalanced three-class light-curve benchmark, class-balanced training, Brier score, candidate ranking |
| Data-quality and spacecraft/instrument issue documentation | Product manifest with SHA-256 hashes, explicit scope, V&V dashboard, structured JSON outputs |
| Concurrent TOLIMAN and bolide work | One release runs two separate science tracks under a shared validation contract |
| Scientific communication and open tools | README, role mapping, validation notes, application figure and reproducible quick start |
